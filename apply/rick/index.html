The proposal

The first semester tests the recording to score pipeline with me in the loop. I hand build the scores while aligning the mechanism to reproduce the work. The next semester I hand off the scoring and mechanism, training others to run it. The goal is to set up a system that eventually culminates without me.

The thesis

The loop closes on itself when I can exit.
